01 / Concept

什麼是隨機漫步？

想像一個人在格線上移動：每一步都由新的隨機結果決定。走過很多步後，位置會形成一條曲折的路徑。

每一步

新增一個隨機變動。

累積效果

目前位置包含過去每一步的影響。

路徑外觀

可能短暫連續上升或下降，但不代表方向可被事先確定。

來源：[S1][S2]

02 / Model

數學模型

\[ Y_t = Y_{t-1} + \varepsilon_t \]
  • \(Y_t\)：第 t 期的數值。
  • \(Y_{t-1}\)：前一期的數值。
  • \(\varepsilon_t\)：當期新增的隨機變動。
\[ Y_t = c + Y_{t-1} + \varepsilon_t \]

加入 \(c\) 後稱為有漂移隨機漫步；c 表示每期平均變動方向與幅度。

來源：[S1][S2]；模型需連同誤差項假設解讀。

03 / Properties

重要統計特性

期望值

無漂移且起始值固定時，\( E(Y_t)=Y_0 \)。

變異數

若隨機變動彼此不相關且變異數固定，\( \operatorname{Var}(Y_t)=t\sigma^2 \)。

非定態性

水準序列的變異數會隨時間增加；差分後可回到隨機變動序列。

重點：過去的隨機變動會累積在水準值中，因此不確定性會隨時間擴大。

來源：[S1][S2][S5]；上述變異數結論依賴明確假設。

04 / Finance

與金融市場有什麼關係？

隨機漫步觀點常用來討論股票價格變動是否能由過去價格資訊系統性預測。

若過去價格型態沒有穩定預測力，單靠歷史圖形尋找交易規則便會面臨挑戰。

請注意

這是模型與假說的討論，不代表所有股票、所有時期都已被證明完全遵循隨機漫步。

來源：[S3][S4]；需保留原研究年代與實證脈絡。

06 / Forecast

為什麼點預測等於最後觀察值？

\[ \widehat{Y}_{T+h\mid T} = Y_T \]

在無漂移隨機漫步設定下，未來新增的隨機變動的期望值為 0，因此最佳點預測會落在最後觀察值。

這不代表

未來價格不會變動。實際路徑仍會受到新的隨機變動；點預測只是條件期望，不是保證值。

來源：[S1][S2]

07 / Limitations

模型限制與常見誤解

  • 隨機漫步是簡化模型，依賴對隨機變動的假設。
  • 市場制度、交易成本與資訊環境可能使真實資料更複雜。
  • 「難以預測」不等於「價格不會變」。
  • 「隨機漫步假說」不等於所有股票永遠完全隨機。

來源：[S3][S4]；限制與實證解讀須回到來源脈絡。

08 / Takeaways

重點整理與參考來源

概念

模型

無漂移與有漂移形式需分清楚。

應用

金融市場應用要區分理論、證據與推論。
