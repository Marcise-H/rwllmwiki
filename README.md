# 隨機漫步模型 LLM Wiki 專案包

本專案包是作業起始套件，主題為「隨機漫步模型（Random Walk）與金融市場應用」。

## 重要說明
- `deck.html` 是可直接開啟的教學簡報初稿。
- `wiki/` 是知識庫初稿，仍需依照你實際下載並 Ingest 的來源逐項核對、補上出處。
- `evidence_cards/` 是五份建議來源的閱讀卡／來源摘要，不等於原始全文。
- `raw/` 請放入你實際下載的至少五份原始來源文件（PDF 或 HTML 存檔）。不要把只有網址的清單當成已完成 Ingest。
- `log.md` 請記錄你真正執行過的步驟與檢查結果，不要填寫未執行的測試。

建議用 Antigravity / Claude Code / 其他能讀取專案資料夾的 AI Agent 開啟本資料夾。
