# 隨機漫步模型（Random Walk）與金融市場應用

本專案以隨機漫步模型（Random Walk）為核心，透過 LLM Wiki 的知識整理流程，建立金融市場相關的教學知識庫，並進一步製作互動式 HTML 教學簡報。

## 專案成果

- **GitHub Repository：** https://github.com/Marcise-H/rwllmwiki
- **線上教學簡報：** https://marcise-h.github.io/rwllmwiki/

## 一、專案目標

1. 理解隨機漫步模型的基本概念與數學表示。
2. 整理隨機漫步模型的統計特性。
3. 探討隨機漫步模型與金融市場、股價變動及效率市場假說的關係。
4. 利用 LLM 協助蒐集、整理及組織知識。
5. 將整理後的知識轉化為具備互動功能的 HTML 教學簡報。

## 三、教學簡報特色

- 使用 LaTeX 呈現數學公式。
- 以 Times 系列數學字體風格呈現公式。
- 提供投影片前後頁切換功能。
- 內建隨機漫步互動模擬器。
- 說明隨機漫步模型在金融市場中的應用與限制。

## 四、使用技術

- LLM Wiki：知識整理與內容組織
- HTML：教學簡報結構
- CSS：頁面排版與視覺設計
- JavaScript：互動功能與隨機漫步模擬
- LaTeX / MathJax：數學公式排版
- GitHub Pages：網站部署與公開展示
